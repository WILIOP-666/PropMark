# Microburbs Guides
44 guides, interactive maps and whitepapers explaining what Australian property data actually shows — and how we measure it.
Most property questions look simple and turn out not to be. Whether a street floods, how much aircraft noise a suburb really gets, what a median price hides, whether a block can be built out — the answer usually depends on data that exists but is scattered across councils, state registries and statistical releases that were never meant to be read together.
These guides are our attempt to put those answers somewhere useful. Some are interactive maps you can search by address. Some are whitepapers explaining a method — how we build a smart median, how we detect a weekly price signal, how we estimate what drives a price. All of them are built on the same Australian property dataset behind our suburb and property reports, and each one shows its working so you can judge it rather than take our word for it.
Start anywhere. They are grouped below by kind.
