**Method:** This analysis uses property and suburb research activity on the Microburbs platform. "Searches" are individual suburb or property report lookups. Search intensity equals searches divided by the number of ABS mesh blocks in each suburb. Ranking changes compare the current period to the same prior period (e.g. this week vs last week).
