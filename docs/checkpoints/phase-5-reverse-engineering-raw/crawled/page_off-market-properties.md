## What are off market properties?
Homes an agent sells without an ad on realestate.com.au™ or Domain™.
Buyer's agents have long used them to make low offers. Across Australia, these homes sold for about 3% less than similar advertised homes nearby. That is about $19,000 on a typical home, July 2023 to April 2026. No measured effect on later growth, rent or yield.
Off market properties, explained in under two minutes. Source: Microburbs research.

## Try this on the API
Paste this request into a terminal to see homes for sale in St Kilda, Melbourne. It is free for St Kilda (Vic.) and eight other suburbs, one in every state and territory, with no sign up and no card. The first line sets the API host.

```
API_HOST=api.microburbs.com.au
curl --proto-default https "${API_HOST}/v1/suburbs/St%20Kilda%20%28Vic.%29/listings/for-sale" \
  -H "Authorization: Bearer test"

```

What came back for St Kilda (Vic.) on 24 September 2026, first few figures of 12,551 characters:

```
{
  "data": {
    "results": {
      "gnaf_pid": "GAVIC425162631",

      "area_name": "Unit 103A, 33 Inkerman Street, St Kilda (Vic.), VIC",

        "street": "Unit 103A, 33 Inkerman Street",
```
