# Current for-sale listings
GET`/v1/suburbs/{suburb_name}/listings/for-sale`20¢ per call
Current for-sale listings in the suburb, with address, price, beds/baths, coordinates and an `off_market` flag per listing.
`total` is the full number on the market (computed before `limit`), so a count is accurate even when the rows are capped. Raise `limit` for more listings; set `verbose=true` for the agent's full description text; set `off_market=true` for off-market listings only.
**Exact suburb identifier required.** Exact ABS Suburb and Locality (SAL) name, e.g. `Burwood (NSW)` — many suburbs carry a state suffix. If starting from free text or an unverified bare name, first call `GET /v1/geocode/suburb?q=<text>`, then use the exact `data[].area_name` it returns. Suburb data endpoints do not guess a state or typo-correct names.
**Price: 20¢ per call.**
## Authorization
Bearer tokentest
Sandbox key `test` works for the allowlisted GNAF + SAL — no signup.
## Request
The only values you send. Fields under Responses below are what comes back — you never pass those.
### Path parameters
`suburb_name`stringrequired
Exact ABS Suburb and Locality (SAL) name, e.g. `Burwood (NSW)` — many suburbs carry a state suffix. If starting from free text or an unverified bare name, first call `GET /v1/geocode/suburb?q=<text>`, then use the exact `data[].area_name` it returns. Suburb data endpoints do not guess a state or typo-correct names.
### Query parameters
`limit`integeroptional
Max listings to return (default 30, max 200). `total` always reports the full match count.
`verbose`booleanoptional
Include the agent's full ad-copy in `attributes.description`. Off by default — it averages ~1.5 KB per listing.
not sent · default false
`off_market`booleanoptional
Only return OFF-MARKET listings: not on realestate.com.au or Domain, sourced from the agency's own site, and still believed live — the Microburbs property finder's 'Off market only' rule. Default false returns every listing, each carrying its own `off_market` flag. `total` counts the filtered set.
not sent · default false
