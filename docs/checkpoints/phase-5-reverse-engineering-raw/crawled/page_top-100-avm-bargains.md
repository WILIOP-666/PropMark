### Methodology
Properties are ranked by dollar savings (AVM value minus listing price). Only properties with a confidence score above 80% are included. The confidence score combines five independent checks:
  * **AVM Reliability** measures how accurate the automated valuation model is for this property type and location.
  * **Data Volume** reflects the number of comparable sales in the surrounding area.
  * **Discount Plausibility** checks whether the discount falls within normal market variation.
  * **Area Alignment** compares the listing price against recent area sales.
  * **Trend Boost** rewards areas where prices are trending upward, widening the gap.


Data sourced from GNAF, ABS Census 2021, and public property records. Generated 2 March 2026.
